Adding fractions with different denominators

Make the pieces the same size before you add them.

Learn & practise

The key idea

The denominator tells you how many equal pieces make one whole. You can only add fractions directly when their pieces have the same size. Find the least common multiple (LCM) of the denominators, then multiply the numerator and denominator of each fraction by the same number.

+
Please use whole numbers, with denominators from 2 to 12 and numerators from 0 to 12.
